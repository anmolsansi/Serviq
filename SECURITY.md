# Security Policy

Please avoid publishing sensitive vulnerability details in a public issue.

Use GitHub private vulnerability reporting for this repository when it is available. If that option is unavailable, contact the repository owner through the GitHub profile and request a private reporting channel before sharing exploit details, credentials, personal data, or other sensitive material.

When reporting a vulnerability, include the affected area, expected and observed behavior, impact, reproduction steps that are safe to share privately, and any suggested mitigation.

Do not include real secrets, access tokens, customer information, or production personal data in a report or reproduction case.
