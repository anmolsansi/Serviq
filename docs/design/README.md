# Serviq Design Mockups

This directory contains the approved high-resolution Serviq product design mockups for the three primary experiences.

| Design | Resolution |
| --- | --- |
| `serviq-client-portal-4k.png` | 3840 × 2160 |
| `serviq-customer-experience-4k.png` | 3840 × 2160 |
| `serviq-platform-operator-4k.png` | 3840 × 2160 |

## Experiences

- **Client Portal** — organization administrators and support teams.
- **Customer Experience** — end-user support journeys and embedded support.
- **Platform Operator Console** — Serviq superadmin and platform operations.

These 4K PNG assets replace the earlier compressed WebP previews and are the approved visual direction for frontend implementation.
